# 따오기 Android 앱

사이트 전체를 주소창 없는 WebView로 표시합니다. 사이트 서버와 인터넷 연결이
필요하며, Android 8.0(API 26) 이상을 지원합니다.

음악 페이지는 `SangkiAndroid` 브리지를 감지해 HTML 오디오 대신 네이티브
`MediaPlayer`를 사용합니다. 전체 대기열과 반복 모드는 `PlaybackService`에 전달하여
웹 페이지가 정지하거나 다른 메뉴로 이동해도 서비스가 다음 곡과 반복을 처리합니다.
일반 브라우저에서는 기존 HTML 오디오 동작을 유지합니다.

서비스는 `mediaPlayback` 포그라운드 서비스, 오디오 포커스, 재생 중 CPU wake lock,
MediaSession과 재생 알림을 사용합니다. 전화/다른 오디오 앱의 포커스 요청과
헤드폰 분리 시 재생을 일시정지합니다. 재생 종료 버튼/알림의 종료로 서비스를 끝냅니다.
Android에서 강제 종료하거나 기기가 종료되면 재생이 멈추며 자동 재시작하지 않습니다.
기기 제조사의 별도 배터리 제한으로 중단될 수 있습니다.

앱 내부 탐색은 `https://jh133-a11y.github.io/sangki/`로 제한합니다.
외부 링크는 외부 앱으로 열고 HTTP 콘텐츠는 앱 내에서 허용하지 않습니다.
네이티브 플레이어는 지정된 Supabase 음악 버킷의 HTTPS URL만 허용합니다.
업로드는 시스템 파일 선택기를 사용하며 저장소 전체 접근 권한은 요구하지 않습니다.
사이트의 로그인 정보는 앱 WebView에 저장되며 브라우저 로그인과 별개입니다.

## 빌드

JDK 17, Gradle 8.11.1, Android SDK Platform 35 및 Build Tools 35.0.0이 필요합니다.
`ANDROID_HOME`을 SDK 경로로 설정하고 이 디렉터리에서 실행합니다.
Windows에서 프로젝트 경로에 한글이 포함되면 Android 빌드 도구가 거부할 수 있으므로,
`android` 디렉터리를 영문 경로의 빌드용 디렉터리로 복사한 뒤 빌드하세요.

```powershell
gradle --no-daemon :app:assembleDebug :app:lintDebug
```

설치 가능한 개발 서명 APK는 `app\build\outputs\apk\debug\app-debug.apk`에 생성됩니다.
개발 서명은 Google Play 배포용 서명이 아닙니다. 업데이트에는 동일한 서명 키가
필요하므로 `~\.android\debug.keystore`를 보관하고 공개 저장소에 올리지 마세요.
릴리스 배포 시 별도의 안전하게 보관한 서명 키로 서명해야 합니다.

## 기기 확인

APK 설치 시 해당 다운로드 앱의 '알 수 없는 앱 설치' 권한을 허용해야 합니다.
알림 권한 요청을 허용하면 재생 알림을 확인할 수 있습니다.
음악 파일 업로드·계정별 목록, 화면 종료 후 자동 다음 곡, 한 곡/전체 반복,
다른 메뉴로 이동 후 재생 상태 복원, 알림/잠금 화면 제어, 헤드폰 분리,
전화 수신, 종료 버튼과 네트워크 오류를 실제 기기에서 확인하세요.
